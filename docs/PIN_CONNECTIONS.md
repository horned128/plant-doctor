# エッジAIテラリウム 配線仕様（現在版）

## 0. 最初に確認すること

このファイルは、現在のプロトタイプ配線を「実際に配線するときに迷わない」ことを優先して整理したものです。

### 使用構成

- ボード：Solist-AI™ 搭載評価ボード `DT-EBML63Q2557`
- I2C HUB V1.0：使用
- 付属MEMS加速度センサ：未使用
- 14ピンIDCハーネス：未使用
- CN3 / CN5 / CN6 へジャンパ線で直接接続
- ポンプ系統は外部5V電源で駆動
- 外部5VをDFR0457でON/OFFし、LXDC55で3.3Vへ降圧してPP310-030へ供給
- Solist-AI™ ボードからポンプ電流を供給しない

---

## 1. 最重要：SEN0204 の GND 配線

SEN0204 の青線（GND）から、**CN6-3とCN5-6へ2本の線を直接出す必要はありません。**

ただし電気的には、次の3点を**同じGND**にする必要があります。

- SEN0204 青線 GND
- CN6-3 GND
- CN5-6 IN0-

推奨配線は次の形です。

```text
CN6-3 GND ─────── SEN0204 青 GND
    │
    └──────────── CN5-6 IN0-
```

つまり、

1. `SEN0204 青 GND → CN6-3`
2. `CN6-3 → CN5-6` を短いジャンパ線で接続

とすればOKです。

### なぜ CN5-6 も必要なのか

CN5 の `IN0+ / IN0-` は、5V入力のフォトカプラ絶縁入力です。

SEN0204は5Vで駆動した場合、

- 液面検出時：OUT ≒ 5V
- 非検出時：OUT ≒ 0V

を出力します。

そのため入力は次のように作ります。

```text
SEN0204 黄 OUT ───── CN5-5 IN0+
SEN0204 青 GND ───── CN5-6 IN0-
```

CN5-6はボードGNDへ内部直結された端子ではないため、今回のようにSEN0204をCN6の5V/GNDで駆動する場合は、**CN6-3とCN5-6を外部で同電位にする**必要があります。

# 3. 電源系統

| 系統 | 使用先 | 供給元 |
|---|---|---|
| 3.3V | SEN0206 / SEN0385 / SEN0228 | Solist-AI™ CN3 Power Out |
| 5V | SEN0193 / SEN0204 | Solist-AI™ CN6-1 Power Out |
| Solist-AI側GND | センサ類 | CN3 / CN6 GND |
| 外部5V | DFR0457制御側 / DFR0457パワー側 | 外部5V・2A以上 |
| 3.3Vポンプ電源 | PP310-030 | LXDC55出力 |
| ポンプ側GND | DFR0457 / LXDC55 / PP310-030 | 外部5V電源GND |

## 3.1 Solist-AI側 3.3V

`JP1` を **3.3V側**に設定します。

CN3のPower Outから以下へ3.3Vを供給します。

- I2C HUB
- SEN0206
- SEN0385
- SEN0228

**DFR0457の制御側には、Solist-AIの3.3Vを使用しません。**

## 3.2 Solist-AI側 5V

`JP6` を **5V側**に設定します。

CN6-1から以下へ5Vを供給します。

- SEN0193
- SEN0204

### 5V電源の有効化

DT-EBML63Q2557の5V電源は、

- ファームウェアから `REG5V_ON` を有効化する  
  **または**
- `JP10` をSHORTして5V DC-DCを強制ONする

必要があります。

試作・配線確認中は、CN6-1に実際に5Vが出ていることをテスターで確認してください。

## 3.3 ポンプ系統：外部5V

ポンプ系統には**Solist-AIとは別の外部5V電源**を使用します。

推奨：

- PSE適合
- 5V
- 2A以上

接続順は次のとおりです。

```text
外部5V
  │
  ▼
DFR0457
  │
  ▼
LXDC55
  │ 3.3V
  ▼
PP310-030
```

Solist-AIは従来どおりUSB-Cから給電します。

**Solist-AIのGNDとポンプ用外部5VのGNDは接続しません。**  
CN5 OUT0のSSR接点を介して制御するため、両系統は電気的に絶縁します。

## 5.4 SB340LS

SB340LSはPP310-030の端子・配線のできるだけ近くに並列接続します。

| SB340LS | 接続先 |
|---|---|
| カソード（帯・線のある側） | ポンプ＋ / LXDC55 `O` |
| アノード（帯のない側） | ポンプ－ / LXDC55 `G` |

```text
LXDC55 O ────────┬──── PP310 +
                 │
                 └──|<|──┐
                    SB340 │
LXDC55 G ────────┴──── PP310 -
```

通常動作中はSB340LSに電流を流さず、ポンプの逆起電力をクランプする向きです。

**ダイオードを逆向きに取り付けると通常通電時に短絡するため、通電前に帯の方向を必ず確認します。**


# 6. CN3：I2Cセンサ

## 6.1 CN3 → I2C HUB

| CN3 Pin | 信号 | HUB |
|---:|---|---|
| 1 | SCL | SCL |
| 2 | GND | GND |
| 3 | SDA | SDA |
| 5 | 3.3V | VCC |

```text
CN3-5  3.3V ───── HUB VCC
CN3-2  GND  ───── HUB GND
CN3-1  SCL  ───── HUB SCL
CN3-3  SDA  ───── HUB SDA
```

## 6.2 HUB → センサ

HUBの各ポートへ以下を接続します。

- SEN0206 葉温センサ
- SEN0385 温湿度センサ
- SEN0228 照度センサ

HUBはI2C信号を分岐するため、3台は同じI2Cバス上に存在します。

```text
I2C HUB
 ├─ SEN0206
 ├─ SEN0385
 └─ SEN0228
```

### 想定I2Cアドレス

| センサ | I2Cアドレス |
|---|---:|
| SEN0206 / MLX90614 | `0x5A` |
| SEN0385 / SHT31 | `0x44` |
| SEN0228 / VEML7700 | `0x10` |

アドレスは重複していません。

なお、DT-EBML63Q2557上のLCDも同じI2Cバスを共有しているため、I2Cスキャンでは上記3台以外のアドレスが見える可能性があります。

# 9. CN5：OUT0 → DFR0457 制御

DT-EBML63Q2557のOUT0はSSRによるA接点として使用します。

**CN5からポンプ電流は流しません。**  
CN5 OUT0は、DFR0457の制御信号を5Vへ切り替えるためだけに使用します。

## 9.1 配線

```text
外部5V ＋ ─────────────┬──── DFR0457 +
                       │
                       └──── CN5-9 OUT0a

CN5-10 OUT0c ───────────── DFR0457 D/S

外部5V － ─────────────┬──── DFR0457 -
                       │
                       └─ 4.7kΩ ── DFR0457 D/S
```

CN5-9 / CN5-10はA接点なので、9と10を入れ替えても接点としての動作は同じです。

## 9.2 OUT0 OFF

```text
CN5-9 ──X── CN5-10

4.7kΩ抵抗
   ↓
DFR0457 D/S = LOW
   ↓
DFR0457 OFF
   ↓
ポンプ停止
```

4.7kΩ抵抗はD/Sを外部5V電源のGND側へプルダウンし、SSR接点が開いているときに入力を確実にLOWへします。

## 9.3 OUT0 ON

```text
CN5-9 ───── CN5-10

外部5V ＋
   ↓
DFR0457 D/S = HIGH
   ↓
DFR0457 ON
   ↓
LXDC55へ5V供給
   ↓
PP310-030動作
```

### 重要

- DFR0457の制御電源は外部5V
- DFR0457のパワー入力も同じ外部5V
- Solist-AI側3.3VはDFR0457へ接続しない
- Solist-AI GNDと外部5V GNDは接続しない
- CN5 OUT0にはDFR0457の制御電流だけを流す
- CN5 OUT0へポンプ電流を流さない


# 10. ポンプ電源：DFR0457 → LXDC55 → PP310-030

## 10.1 全体接続

```text
              外部5V電源
            ┌────────────┐
            │            │
            │ +          │ -
            ▼            ▼
       DFR0457 VIN   DFR0457 GND
            │            │
            │            └──────────────┐
            ▼                           │
       DFR0457 VOUT                     │
            │                           │
            ▼                           ▼
         LXDC55 I                    LXDC55 G
            │                           │
            │   3.3V                    │
            ▼                           │
         LXDC55 O                       │
            │                           │
            ├──────── PP310-030 ＋      │
            │                           │
            └── SB340LS ────────────────┤
                                        │
                             PP310-030 －┘
```

## 10.2 LXDC55

LXDC55は外部5Vを3.3Vへ降圧してPP310-030へ供給します。

基板シルク：

- `I`：4.3～14V入力
- `G`：GND
- `O`：3.3V出力

LXDC55は最大1.5A出力で、PP310-030の最大電流900mAに対して容量上の余裕があります。

## 10.3 PP310-030

```text
LXDC55 O ───── PP310-030 ＋
LXDC55 G ───── PP310-030 －
```

ポンプの線色が赤・黒の場合は通常、

- 赤：＋
- 黒：－

です。

極性を逆にするとポンプの回転方向が逆になり、吸入口と吐出口が入れ替わる可能性があります。

## 10.4 SB340LS

ポンプのできるだけ近くへ並列に取り付けます。

```text
            PP310-030
           ┌────────┐
3.3V + ────┤ +    - ├──── GND
   │       └────────┘      │
   │                       │
   └─────|<|───────────────┘
         SB340LS

カソード（帯） → ＋
アノード       → －
```

接続部は熱収縮チューブなどで確実に絶縁します。

## 10.5 ヒューズ

常設時は、外部5V電源の＋側に**1Aタイムラグヒューズ**を追加することを推奨します。

```text
外部5V ＋
   │
 [1A T]
   │
   ├──── DFR0457 VIN
   └──── DFR0457 制御側 / CN5-9
```

- [ ] 外部5V＋ → CN5-9 OUT0a

## ポンプ電源側

- [ ] 外部5V電源がPSE適合・2A以上
- [ ] 外部5V＋ → DFR0457 VIN
- [ ] 外部5V－ → DFR0457 GND
- [ ] DFR0457 VOUT → LXDC55 `I`
- [ ] DFR0457 GND → LXDC55 `G`
- [ ] LXDC55 `O` → PP310-030 ＋
- [ ] LXDC55 `G` → PP310-030 －
- [ ] LXDC55出力が約3.3Vであることをポンプ接続前に確認
- [ ] SB340LSの帯側がポンプ＋
- [ ] SB340LSの帯なし側がポンプ－
- [ ] SB340LSをポンプのできるだけ近くに配置
- [ ] ポンプ電流経路に細いDupont線やブレッドボードを使っていない
- [ ] ポンプ電流配線はAWG22程度
- [ ] 常設時は外部5V＋側に1Aタイムラグヒューズを検討
- [ ] VCC-GND間の短絡がない

## 初回動作確認

1. PP310-030を外した状態でSolist-AIとセンサを起動
2. SEN0204 / SEN0193 / I2Cセンサの値を確認
3. 外部5Vを投入
4. DFR0457 OFF時にLXDC55入力へ電圧が出ていないことを確認
5. OUT0をONし、DFR0457 VOUTが約5Vになることを確認
6. LXDC55 `O-G`間が約3.3Vであることを確認
7. 電源OFF
8. PP310-030とSB340LSを接続
9. 短時間だけポンプをONして吸排水方向を確認
