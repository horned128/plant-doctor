# Plant Doctor ファームウェア

DT-EBML63Q2557（ROHM ML63Q2557、Arm Cortex-M0+）上で動作する、Plant Doctorの
ベアメタルファームウェアです。このディレクトリはアプリケーション固有のソースを、
`../../CommonFiles/`は変更しないベンダー提供の共通モジュールを保持します。

## 現在の動作

- 電源自己保持、5 Vレギュレータ、10 msシステムTick、LED、4個のスイッチ、LCDを制御する。
- SEN0206、SEN0385、SEN0228、SEN0193、SEN0204を1秒周期で取得する。
- LCDは3つのセンサーページを5秒周期で切り替え、表示中の値は1秒周期で更新する。値が無効な場合は`--`を表示する。
- AI、ポンプ、ログは、今後の実装に備えたモジュール境界として存在する。

設計上の責務分割、タイミング、I2C共有、LCDの各表示・エラーは、
[ML63Q2557ファームウェア設計](../../../../docs/firmware/ml63q2557/ARCHITECTURE.md)を
正とします。配線は[ピン接続](../../../../docs/PIN_CONNECTIONS.md)を参照してください。

ビルド、書き込み、デバッグは[VS Code開発環境](../../../../docs/VSCODE_SETUP.md)を参照してください。
